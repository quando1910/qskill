# qskill

Qskill is a collection of personal development workflow skills.

Available workflows:

- `push-code`: review, commit, push, and open a pull request for the current repository changes.

Use the relevant qskill command or ask Claude to apply the matching skill. The detailed workflow is stored in `skills/push-code/SKILL.md`.
